Trackspace Logo options

Thirty-four marks to replace the current logo

Each one is a geometric SVG built for the same job the current mark does: a 32 px header mark, a 16 px favicon, and a single flat colour. Set A is direct, Set B takes more risk, Set C is spacecraft, and Set D works the habitat mark eight ways. Pick a number and I will wire it into the app, the icon, and the manifest.

What the mark must do

The header mark is drawn as a CSS mask filled with --ts-ink, so the artwork has to work as one flat shape. These constraints shaped every option below.

  • One colour. No gradients, no multi-tone fills, no strokes that depend on a second colour.
  • Legible at 16 px. Minimum stroke weight is 3 units on a 64 unit grid, which is about 0.8 px at favicon size.
  • Optical balance in a square. Every mark centres in a 64×64 box with a 8–10 unit margin, so it drops into the existing 32 px slot with no layout change.
  • Pairs with the wordmark. The wordmark is monospace, uppercase, tight. The mark stays geometric so it does not fight it.

The current mark

For comparison. It is a detailed illustration: many small parts, several separate dots and hairlines. At 32 px the detail turns to noise, and at 16 px most of it disappears.
